## 二、Introduction

《Inkward Bound》是一件互动生成装置,以墨为材料,探讨意识的空间化。当意识在时间中的生成被 AI 接管、被摊平为可检索的坐标,观众用手在这片空间里移动、等待,墨随之扩散、扰动、聚拢;在系统不立即服从的那几秒里,时间重新有了厚度,朝向内里。

作品把潜空间——模型内部真实存在却不可见的计算空间——当作概念场域,并让整条管线执行它所讨论的事。自行拍摄的墨在水中的影像被切成帧、按状态分组标注,训练成 LoRA 模型;这些状态在潜空间中被映射为一条 0 到 1 的坐标轴,再通过多 seed 生成与插帧,预先烘焙成一份可检索的图集。连续的流由此变成可被索引的位置——这正是作品所描述的那次转换,只不过发生在管线里,而非观念中。

观众触摸屏幕,C 值随之变化。按压时 C 值向目标平滑逼近而不会到达,松开后以恒定速率缓缓退回,当前画面取决于此前的输入,而非此刻的指令。那段迟滞不是交互上的润色,它是整件作品里唯一具有时间性的部分。

作品不判断聚合是否意味着修复,也不判断弥散是否意味着失去,而是把这个问题交还给身体——交还给按住、等待、松开的那段时间。

## 三、Concept:从时间存在性变成空间存在性

**入口|现象:意识外逃** — 当意识在时间中的生成被 AI 接管

### 1. 意识本来是什么

意识在时间中生成——绵延、持存与前摄。

**▸ 有先后、有铺开的过程**

*张祥龙、柏格森(durée)、胡塞尔*

绵延是质的多样性:各时刻相互渗透,没有边界,数不出来。听一段旋律,此刻这个音之所以是它,是因为前面的音仍在它里面起作用。胡塞尔的结构更精细:每个当下都携带刚过去的**持存**与朝向下一刻的**前摄**——当下是有厚度的,不是一个点。

*回答:被接管的是什么。*

### 2. 接管与转换如何发生

空间化——从相互渗透到彼此外在。

**▸ 有坐标、有位置、可以被检索**

*柏格森*

- **能数,是因为彼此外在。** 计数预设并置;桌上三个杯子互不进入,所以可以数。
- **表征必然造成转换。** 要呈现一样东西就得给它形式,形式意味着边界,边界意味着位置,位置意味着并置。这一步绕不开。
- **潜空间即标准的彼此外在。** 向量各占坐标、可算距离、可插值。C 轴 0—1 就是给一个不可分解的过程分配位置。

**必须守住的界线:**

> 柏格森的诊断成立,处方无对应物——空间化由技术系统在意识之外执行,不能靠反省取消。

柏格森面对的是意识内部的习惯,可以反省、可以悬置,所以他能主张回到绵延。这里的空间化发生在意识之外,不因态度改变而改变。**这条界线是"不裁定"立场的来源**:不是姿态上的开放,而是可供裁定的那个位置已经不存在了。

*回答:转换如何发生,以及为什么不能主张回去。*

### 3. 数据化与 pharmakon

**一句话:只能被感受的多,变成了可以被检索的多。**

*斯蒂格勒(语法化 grammatisation、第三持存、pharmakon)/ 胡塞尔 / 德里达《柏拉图的药》/ 柏拉图《斐德罗篇》/ Paglen*

- **并非孤例。** 连续的流被切成可存储、可重组、可检索的元素——文字、印刷、机械、录音、数字,同一操作在不同层面反复推进。*(这一行必须留着:书写在序列里,墨的论证才成立。)*
- **被拿走的是前摄,不是记忆。** 推荐、补全、预测替观众完成了"接下来是什么"。当下一刻总是被预先给出,当下便失去了厚度。
- **观看本身也被数据化。** 图像不再首先是被观看的对象,而成为被检索与处理的单元(Paglen, 2016)。
- **pharmakon。** 药与毒同为一词,不可拆分。文字的数据化让哲学成为可能,同时让记忆退化成为可能——两者是同一件事,不是副作用。

**必须守住的界线:**

> 价值中立由 pharmakon 内建,不需另行声明。

*回答:这个转换有多古老,以及为什么它不是一次单纯的损失。*

### 4. 一种无法被空间化的知

有一种知只在行动正在发生时成立,离开当下就不再是它自己。它没有可存放的形式,因此不能被数据化。

*梅洛-庞蒂;Varela / Thompson / Rosch;王阳明*

- 知觉**不是**内部剧场上演的表象,而是身体与世界交互本身。
- 知行合一:知不先于行而存在,也不能脱离行被保存。

**必须守住的界线:**

> 此为机制解释,非处方——它说明形式的必然性,不主张身体是解药。

*回答:为什么必须是触摸,以及为什么必须是连续的。*

### 前提|不预设结果

intra-action 使人与系统的关系保持为相互构成,而非一方作用于另一方(Barad)。

*此项框住全链,不参与顺序。*

## 四、Metaphor:为何是墨

**整支论点:** 墨不是意识的比喻。它是被空间化之前的状态的物质形态,同时是空间化最初的技术,并在两个传统中承担同一功能。

### 1. 墨的两种状态(现象学层面)

*柏格森 — 质的多样性 / 量的多样性*

- **水中的墨** — 相互渗透,没有边界,数不出来 → 尚未被空间化的状态
- **纸上的墨** — 干了,有形状,占据位置,可指认 → 已经是空间化的产物

选择水中的墨,即是选择尚未成为对象的那个状态。

*挡住:换成纸、烟、沙行不行。*

### 2. 墨与技术同源(结构层面)

*Sohl-Dickstein et al., 2015 / 德里达、斯蒂格勒 pharmakon*

- **与扩散模型同源** — 两者都从噪声走向形态;这一数学结构本就源自对物理扩散过程的研究,不是命名上的巧合。
- **墨即最早的空间化技术** — 把流动的思想固定为可见痕迹,是"存下来"这件事的第一个版本。

墨因此承担双重身份:既是被空间化之前的样子,又是空间化最初的工具。

*挡住:这是不是只是外观类比。*

### 3. 墨的文化位置(语境层面)

*王阳明 知行合一 / 梅洛-庞蒂、Varela*

东西方共通的书写、记忆与痕迹载体。它被选用不是作为文化符号,而是因为它在两个传统中承担同一功能——正如上述两条理论线在两种语言中说同一件事。材料的双重归属与理论的双重归属结构一致。

*挡住:中国哲学是不是文化装饰。*

## 五、技术空间化:墨如何被摊平

| 步骤 | 操作 | 墨发生了什么 |
|---|---|---|
| 1 拍摄与切帧 | 连续影像 → 离散帧 | 流动被切成一格一格 |
| 2 分组与标注 | 帧 → 四组状态 + 文本 | 状态被命名为类别 |
| 3 LoRA 训练 | 图像 → 权重与特征 | 墨成为特征分布 |
| 4 潜空间映射 | 特征 → C 轴 0—1 | 每个状态有了坐标 |
| 5 多 seed 生成 + 插帧 | 坐标 → 预烘焙图集 | 可检索;连续性被缝回 |

> 每一步都让墨更可被检索。最后一步试图把连续性重新造出来——这正是作品在问的事。

**两个可以直接用于答辩的论点:**

**预烘焙不是妥协,是论点。** 图集意味着生成已经完成:观众看到的一切都已存在于一个可检索的结构里,没有任何东西在观众面前"正在生成"。这正是作品要说的事。如果画面真的在时间中生成,作品反而自相矛盾。

**插值是诚实的。** SLERP、LERP 与插帧所做的,是在两个彼此外在的位置之间填出连续性。流畅是缝出来的,不是本来就有的。作品不假装实现了连续性,它展示了连续性是被制造出来的。

**操作性图像。** 图集中的图像首先为被检索与插值而存在,而非为被观看(Parikka)。观众看到的只是这个操作结构在某个坐标上的截面。

## 六、装置结构

### 交互

观众触摸屏幕,C 值随之变化。按压时 C 值向目标平滑逼近而不会到达,松开后以恒定速率缓缓退回,当前画面取决于此前的输入,而非此刻的指令。

C 值不是位置的读数,而是**手势在时间中的积分**:按压时长占七成权重(按满十八秒才抵达上限),稳定度占三成,躁动则是减分项。因此不存在"直接把它调到 1"的操作——只能按住、不动、等。等待被写进了公式本身,而不是被要求于观众。

**这是胡塞尔那一层的物质实现:**

- 慢启动(按下不立刻响应)= 前摄。你不知道接下来会是什么,必须等。
- 缓慢退回(松开不立刻回弹)= 持存。刚过去的仍在起作用。
- 当前状态由此前输入决定 = 当下是有厚度的,不是一个点。

这段迟滞由两处叠加而成:浏览器端计算出 C 值,TouchDesigner 再以不对称的 Lag(上升 0.4 秒、回落 2.5 秒)与高斯滤波进一步塑形。回落远慢于上升——**聚拢比消散更需要时间**,这一不对称是被明确设定的,不是副产品。

那段迟滞是整件作品里唯一真正具有时间性的部分。系统不立即服从,同时也是 Barad:结果由持续的来回决定,不由任何一方单独决定。

### 两块屏幕

| | 主屏 | 副屏 |
|---|---|---|
| 内容 | 墨的状态变化 | 机器视觉读数、坐标、参数 |
| 视角 | 正面 | 俯视 |
| 位置 | 你在里面 | 你在上方 |
| 对应 | 质的多样性 | 量的多样性 |
| | 人的看 | 机器的看 |

*Paglen(2016):两种看并存,不通约,谁也不是谁的注解。*
*Parikka:副屏即操作层的显形。*

**非序列关系。** 两块屏同时在场,地位平等。若必须先主屏后副屏,副屏就成了说明书,并暗示数据那一边更真实。观众自己在两种存在方式之间来回——每次切换视线,都在亲身做一次空间化。

### 为什么是触摸

装置不解释自己:没有说明、没有可见滑杆、没有"读懂了再操作"的路径。理解只能在做的过程中发生。观众按住、等待、松开的那段时间,不是通向理解的路径,它本身就是理解。

## 七、立场

作品不判断聚合是否意味着修复,也不判断弥散是否意味着失去,而是把这个问题交还给身体——交还给按住、等待、松开的那段时间。

**这一立场的来源不是姿态,而是理论内部的推论:** 可供裁定的那个位置(一个能够反省、能够选择回去的意识)在这里已经不存在了。
